Ce qui le distingue

  • La façade : chaque étage est un type de chambre. Les fenêtres allumées sont les chambres occupées ; le prix de la nuit se règle à côté de chaque étage. On voit d'un coup d'œil quel type est plein (prix trop bas) ou vide (prix trop haut).
  • Le tableau des clés : une clé encore accrochée est une chambre libre ce soir. La surréservation et les plateformes s'y règlent, avec le risque expliqué.
  • La semaine : les séminaires remplissent les jours ouvrés, les mariages le samedi ; on voit ce qu'il manque pour combler chaque jour.
  • La plaque des étoiles : 3, 4, 5 étoiles, Palace, puis les resorts à l'étranger.
  • Ambiance marine, laiton et marbre, titres en lettres de grand hôtel.

Les montants et les noms sont des exemples.
